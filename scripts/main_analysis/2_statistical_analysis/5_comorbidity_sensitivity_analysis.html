Overview

Goal: test whether baseline-derived BD risk clusters carry unique BD-specific signal (vs a broader, transdiagnostic signal) by modeling longitudinal diagnostic group membership:

  • any_bsd (replicate prior BD occurrence logic, but using the validated KSADS-derived BSD indicator)
  • dx_other_any (any comorbidity umbrella dx)
  • dx_group4 contrasts vs No Dx:
    • BSD only vs No Dx
    • BSD + other Dx vs No Dx
    • Other Dx only (no BSD) vs No Dx

Primary approach: marginal logistic GEE (geepack::geeglm), cluster x wave, with your existing covariates and (optionally) baseline-status adjustment. We keep the same “GEE-by-wave ORs” workflow via emmeans as your prior scripts.

Disorder-specific models (Reviewer 1, comment 4): the same occurrence GEE is fit separately for each comorbidity set (ADHD, anxiety disorders, depressive disorders, PTSD, ODD/CD), and a stacked GEE across BSD and all five sets formally tests whether the cluster effect for BSD differs from the cluster effect for each comorbidity (ratios of odds ratios).

Note on sparse cells: BSD-only at ses-02A is extremely rare (n~3). The script includes a guardrail to drop wave(s) with very low event counts for that outcome only (default threshold = 5), and refactors the wave reference level for sparse outcomes (default = ses-04A).

5.6 Stacked Specificity Test

A single GEE over long data (one row per participant x wave x disorder, for BSD and the five comorbidity sets), clustered by participant. Each disorder x wave cell has its own intercept and its own cluster coefficient, and covariates (sex, age, baseline status of that disorder) are estimated separately per disorder, so the cell-specific cluster effects parallel the separate models but share one robust covariance. That joint covariance is what allows the cluster effect for BSD to be compared formally with the cluster effect for each comorbidity, as a ratio of odds ratios (ROR > 1: the cluster difference is larger for BSD). An independence working correlation is used, as is standard when stacking distinct outcomes; inference rests on the robust (sandwich) covariance.
